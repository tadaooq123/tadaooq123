# Модпак для CurseForge

`manifest.json` — модпак CurseForge (Fabric 1.21.1): CurseForge сам скачает Fabric API (файл 8786256) и Simple Voice Chat (файл 9350479).

Чтобы собрать архив для импорта: положи `manifest.json`, `modlist.html` и `overrides/mods/BlindDeafMute-fabric-1.21.1-1.0.0.jar` (из `fabric-mod/build/libs/`) в один zip — `manifest.json` в корне.

Импорт: CurseForge → Minecraft → Create Custom Profile → import → выбрать zip.
