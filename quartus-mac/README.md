# Quartus Prime Lite на Mac

Официально Quartus работает только на Windows и Linux. Этот набор скриптов запускает
настоящий **Quartus Prime Lite 25.1** (Linux-версию) на Mac внутри Docker, а окно Quartus
открывается во вкладке браузера. Плата прошивается прямо из macOS.

Работает на Маках с **Apple M1–M5** (через Rosetta) и на **Intel**.

## Что понадобится

- macOS 14 или новее, от 8 ГБ памяти (лучше 16);
- **~40 ГБ** свободного места;
- **Docker Desktop**: https://www.docker.com/products/docker-desktop/ — бесплатно для учёбы.
  При скачивании выбери **Apple Chip** или **Intel Chip** (смотри  → «Об этом Mac»).
  Установи, запусти один раз и пройди приветствие (регистрироваться не обязательно).
  На Маке с M-чипом проверь: Docker → Settings → General → включено
  **«Use Rosetta for x86_64/amd64 emulation on Apple Silicon»**.

## Установка

1. Скачай эту папку `quartus-mac` (на GitHub: **Code → Download ZIP**, потом распакуй).
2. Открой **Терминал** (Cmd+Пробел → «Терминал»), напиши `bash ` (с пробелом),
   перетащи в окно файл **`1. УСТАНОВИТЬ Quartus.command`** и нажми Enter.
   > Двойной щелчок тоже работает, но macOS может сказать «не удалось проверить
   > разработчика». Тогда: Системные настройки → Конфиденциальность и безопасность →
   > внизу «Всё равно открыть». Через Терминал этого шага нет.
3. Жди. Установщик скачает ~6 ГБ с официального сайта Altera и установит Quartus.
   Это 30–90 минут, Mac держи на зарядке.
   Если скачивание не удалось, установщик откроет ссылки в браузере. Когда файлы
   скачаются в «Загрузки», запусти установщик снова: он продолжит с того же места.

По умолчанию ставятся семейства **Cyclone IV, Cyclone V, MAX II/V и MAX 10**: этого хватает
почти для всех учебных плат. Чтобы поставить только нужное (быстрее и меньше места),
запусти установщик так, например только для MAX 10:

```bash
DEVICES="max10" bash "1. УСТАНОВИТЬ Quartus.command"
```

Названия: `cyclone` (Cyclone IV), `cyclonev`, `max` (MAX II/V), `max10`, `cyclone10lp`, `arria_lite`.

## Как пользоваться

| Что сделать | Файл |
|---|---|
| Открыть Quartus | `2. ЗАПУСТИТЬ Quartus.command` — Quartus откроется в браузере |
| Прошить плату | `3. ПРОШИТЬ плату.command` |
| Удалить всё | `УДАЛИТЬ Quartus.command` (проекты останутся) |

- **Проекты храни в папке `FPGA`** в своей домашней папке на Mac. Внутри Quartus она
  называется **`/projects`**. Всё, что лежит в других местах внутри Quartus, пропадёт
  после выключения.
- Выключить Quartus: **File → Exit** или Enter в окне Терминала, из которого он запущен.
- Копировать текст между Mac и Quartus: слева в браузере есть панель noVNC → **Clipboard**.

### Прошивка платы

Quartus внутри Docker не видит USB, поэтому кнопка **Programmer** в Quartus работать не
будет. Вместо неё:

1. Скомпилируй проект в Quartus (**Processing → Start Compilation**).
2. Подключи плату к Mac и включи её.
3. Открой `3. ПРОШИТЬ плату.command` и выбери:
   - **1 — загрузить** `.sof` в плату. Работает со всеми платами; прошивка держится до
     выключения питания. На лабах обычно нужен именно этот вариант.
   - **2 — записать навсегда** `.pof`. Только для MAX II, MAX V и MAX 10.

Скрипт сам найдёт свежий файл прошивки в папке `FPGA` (или перетащи нужный файл мышкой),
при первом запуске поставит программу [openFPGALoader](https://github.com/trabucayre/openFPGALoader)
через Homebrew и прошьёт плату через USB-Blaster или USB-Blaster II. Драйверы на Mac ставить не нужно.

| Плата | Семейство |
|---|---|
| Terasic DE10-Lite | MAX 10 |
| Terasic DE0-Nano, китайские платы на EP4CE6/EP4CE10 (RZ-EasyFPGA, Omdazz и т. п.) | Cyclone IV |
| Terasic DE0-CV, DE1-SoC, DE10-Nano | Cyclone V |
| Платы на EPM240/EPM570 | MAX II |

## Что не работает

- **Симулятор Questa (ModelSim)** не установлен: под Rosetta он не запускается. Для симуляции
  подойдёт [EDA Playground](https://www.edaplayground.com/) в браузере или Icarus Verilog
  (`brew install icarus-verilog`).
- **Signal Tap** и **Programmer** внутри Quartus: у них нет доступа к USB.
- Постоянная запись во flash для **Cyclone** (`.jic`) не поддерживается: используй загрузку `.sof`.
- Под Rosetta Quartus работает медленнее, чем на обычном Windows-ноутбуке, так что
  компиляция может идти заметно дольше.

## Если что-то пошло не так

- **«Quartus ещё не установлен»**: сначала запусти установщик.
- **Docker не запускается**: открой приложение Docker вручную и дождись зелёного статуса.
- **Quartus сразу закрывается** на Mac с M-чипом: проверь галочку Rosetta в настройках Docker
  (см. выше) и обнови Docker Desktop.
- **Плата не прошивается**: проверь питание платы и кабель (некоторые кабели только заряжают),
  попробуй другой порт или переходник. Команда `openFPGALoader --detect` в Терминале
  должна показать ПЛИС.

Другие варианты, если этот не подойдёт:
[quartus-for-mac](https://github.com/any-0/quartus-for-mac) (Linux-VM, прошивает DE0-Nano),
Windows через Parallels (на Intel-Маке ещё и Boot Camp) или компьютеры в лаборатории.

## Как это устроено

- `docker/Dockerfile` ставит официальный установщик Quartus Prime Lite 25.1 (Linux) в образ
  Ubuntu 22.04 для x86_64. Файлы проверяются по SHA-256.
- Под Rosetta нужны два исправления (те же, что в [nixpkgs](https://github.com/NixOS/nixpkgs)):
  инструкция `ffreep`, которую Rosetta в macOS 26 не поддерживает, заменяется равнозначной
  `fstp` (`docker/patch_ffreep.py`), и отключается проверка процессора на SSE в `qenv.sh`.
- Окно Quartus рисуется на виртуальном экране (TigerVNC) и показывается в браузере через noVNC
  на `localhost:6080`; доступ есть только с этого Mac.
- Прошивка: `quartus_cpf` в контейнере переводит `.sof`/`.pof` в `.svf`, а `openFPGALoader`
  на Mac загружает его в плату.
