=====================================================
   СЛЕПОЙ, ГЛУХОЙ, НЕМОЙ — мод для Minecraft 1.21.1
=====================================================

УСТАНОВКА (каждому игроку) — АВТОМАТИЧЕСКИ
------------------------------------------
0. Сначала РАСПАКУЙ архив (правой кнопкой -> "Извлечь всё").

Windows: дважды щёлкни "УСТАНОВИТЬ (Windows).bat".
   Если Windows покажет синее окно "Система защитила компьютер" —
   нажми "Подробнее" -> "Выполнить в любом случае".

Mac: щёлкни ПРАВОЙ кнопкой по "УСТАНОВИТЬ (Mac).command" -> "Открыть"
   -> ещё раз "Открыть" (macOS спросит один раз, т.к. файл не из App Store).
   Если не открывается: Терминал -> напиши  bash  и пробел,
   перетащи этот файл в окно Терминала и нажми Enter.

Скрипт сам:
   - положит мод и Fabric API в папку mods игры;
   - скачает голосовой чат Simple Voice Chat;
   - установит Fabric 1.21.1 (если найдёт Java).
Потом запусти лаунчер и выбери версию Fabric 1.21.1
(в TLauncher — "Fabric 1.21.1", в обычном — "fabric-loader-1.21.1").


УСТАНОВКА ВРУЧНУЮ (если скрипт не сработал)
-------------------------------------------
1. Fabric: TLauncher — выбери в списке "Fabric 1.21.1", один раз запусти и закрой.
   Обычный лаунчер — запусти installer/fabric-installer-1.1.2.exe
   (на Mac — installer/fabric-installer-1.1.2.jar), версия 1.21.1 -> "Установить".

2. Открой папку игры:
   Windows: Win+R -> %appdata%\.minecraft -> Enter.
   Mac: в Finder Cmd+Shift+G -> ~/Library/Application Support/minecraft
   (в TLauncher можно нажать кнопку с папкой)
   Если там нет папки "mods" — создай её.

3. Скопируй все файлы из папки "mods" этого архива в папку mods игры.

4. Скачай Simple Voice Chat (ярлык в архиве), версию для Fabric 1.21.1,
   и тоже положи в mods.

MAC И МИКРОФОН: при первом запуске разреши доступ к микрофону.
Если голос не передаётся — Системные настройки -> Конфиденциальность
и безопасность -> Микрофон -> включи свой лаунчер (или Java).

У всех должны стоять ОДИНАКОВЫЕ моды.


КАК ИГРАТЬ ВМЕСТЕ
-----------------
1. Один игрок (хост) создаёт мир -> Esc -> "Открыть для сети".
2. Остальные заходят:
   - в одной домашней сети мир сам появится в списке серверов;
   - через интернет — все ставят Radmin VPN (или ZeroTier),
     заходят в одну сеть, хост открывает мир для сети,
     остальные подключаются по его IP из Radmin VPN и порту,
     который игра написала в чат.
3. Хост пишет в чат:  /bdm start
   (читы для этого включать не нужно)


РОЛИ (меняются каждые 10 минут)
-------------------------------
СЛЕПОЙ — ничего не видит, но слышит и говорит. Чат не видит.
  F — "Эхо": звенят колокольчики там, где стоят союзники.
  Ближайший моб "стучит", рядом с врагом — сердцебиение,
  рядом с лавой — шипение.

ГЛУХОЙ — не слышит НИЧЕГО: ни звуков игры, ни голосового чата.
  Говорить может.
  F — "Взгляд": союзники подсвечиваются на 5 секунд.
  Над хотбаром — стрелка к ближайшему врагу.

НЕМОЙ — всё видит и слышит, но микрофон, чат,
  таблички и книги ему недоступны.
  F — "Хлопок", Shift+F — "Тревога" (звук + частицы).
  Глухому рядом приходит подсказка "машет тебе ←".

Цель — убить Эндер-дракона.
У команды 5 общих жизней. Каждый раунд — задание:
выполнили — награда и +1 жизнь, провалили — проклятие.


КОМАНДЫ
-------
/bdm info      — правила
/bdm roles     — у кого какая роль
/bdm start     — начать (хост)
/bdm stop      — закончить (хост)
/bdm swap      — сменить роли сейчас (хост)
/bdm interval 5  — менять роли каждые 5 минут (хост)

Настройки: у хоста в папке игры, файл config/blinddeafmute.json


ПРОЧЕЕ
------
Папка "Для сервера Paper" — версия-плагин для настоящего сервера Paper.
Для обычной игры с друзьями она НЕ нужна.

Мод ещё не проверялся в игре с живыми игроками —
если что-то сломалось, сообщи, что написала игра.
